# 版本控制：提交 RAG 系统优化代码

响应你的请求，在深入讨论架构优化之前，先将当前稳定的代码版本保存到 Git。

## 提交内容摘要
本次提交将包含从“基础版”到“本地高性能版”的所有核心变更：

1.  **架构重构 (Architecture)**
    *   **向量库**: 从 Faiss 迁移至 **ChromaDB**，支持持久化存储与元数据过滤。
    *   **数据处理**: 引入 `pymupdf4llm` 进行 Markdown 结构化解析。
    *   **索引优化**: 将切分粒度从 512 调整为 **256 tokens**，显著降低本地显存压力。

2.  **检索增强 (Retrieval)**
    *   **混合检索**: 实现 **Vector + BM25** 双路召回。
    *   **融合排序**: 引入 **动态 RRF 权重**（根据查询长度自动调整 Vector/BM25 权重）。
    *   **重排序**: 集成 `BAAI/bge-reranker` 进行二次精排。

3.  **性能与体验 (Performance & UX)**
    *   **流式输出**: 新增 `/chat/stream` 接口与 Streamlit 流式渲染，彻底解决大模型超时问题。
    *   **超时策略**: 针对本地推理优化了超时阈值 (120s)。

4.  **工程化 (Engineering)**
    *   **代码汉化**: 核心文件（Pipeline, Router, Build Script）注释全面中文化。
    *   **依赖管理**: 新增 `chromadb`, `rank_bm25`, `flag_embedding` 等依赖。

## 执行步骤
1.  检查 Git 仓库状态（如未初始化则初始化）。
2.  执行 `git add .` 暂存所有更改。
3.  执行 `git commit` 提交更新，并附带上述详细说明。
